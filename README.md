# 我的作品集

GitHub Pages 作品展示站。

## 📦 发布新作品

### 方式一：发布 HTML 页面

1. 把做好的 HTML 文件复制到 `works/` 文件夹
2. 打开 `assets/works.js`，在 `works` 数组里添加作品信息
3. 提交并推送 GitHub

### 方式二：发布文档/小说

支持 PDF、图片、Markdown 等文件：
1. 文件放入 `works/` 文件夹
2. 在 `assets/works.js` 中添加作品卡片
